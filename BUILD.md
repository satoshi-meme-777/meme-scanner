# Building the Android app

1. Install Android Studio (latest stable).
2. Open the `android` folder as a project.
3. Let Gradle sync (it will download dependencies).
4. Create a default launcher icon if prompted (or use Image Asset Studio).
5. Run on emulator / device, or Build → Generate Signed Bundle / APK.

If Gradle wrapper is missing, Android Studio will offer to generate it.

Min SDK 24, target 34, Kotlin + Compose.
